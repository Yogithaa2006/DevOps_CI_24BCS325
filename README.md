# Medical Laboratory Test Management System

## Project Description

The Medical Laboratory Test Management System is a software application designed to manage laboratory-related activities such as patient registration, laboratory test catalog management, test requests, and sample collection tracking.

## Main Features

- Patient Registration
- User Login
- Test Catalog Management
- Test Request and Booking
- Sample Collection Tracking

## Current Implementation

This version demonstrates the following modules:

- Patient Registration
- Laboratory Test Catalog
- Test Request Management
- Automated Test Cases
